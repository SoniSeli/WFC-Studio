# WFC Studio (package)

Designer-friendly procedural map generation for Unity 6 using the Wave Function Collapse algorithm.

This package is in early development. See the [repository README](https://github.com/SoniSeli/WFC-Studio#readme) for features, install steps and the roadmap.

| Assembly | Purpose |
|---|---|
| `WfcStudio.Core` | Solver in plain C#. No `UnityEngine` references. |
| `WfcStudio.Runtime` | Unity integration: tile set assets, Tilemap output, visualization. |
| `WfcStudio.Tests` | EditMode tests. |
