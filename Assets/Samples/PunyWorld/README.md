# Puny World Tile Sets

Six WFC Studio tile sets built from the Puny World pixel art, plus a scene to generate with.

| Tile set | What it makes |
|---|---|
| Meadow | Grass, flowers, bushes and trees |
| Lake | Meadow with lakes |
| Forest | Meadow with forests and small groves |
| Mountain | Meadow with mountains, plateaus and higher terraces |
| Castle | Meadow with 3×3 castles |
| Overworld | All of the above together |

## Try it

- Open **Puny World.unity** and press Play to watch a map generate, with the entropy heatmap.
- Or open **Window → WFC Studio**, select the **WFC Generator** in the scene, and generate in Edit mode. Ctrl+Z undoes a map.
- To fix tiles in place, use the window's **Pins** section: **Create Tile Palette**, then **Paint Pins**, then **Generate**.

Each tile set is an ordinary asset: select one to see its sockets, tiles, weights and exceptions in the Inspector, or browse it in the WFC Studio window's **Tiles** section.
